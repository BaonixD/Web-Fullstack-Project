# Frontend

Angular client for the OneTake application. The full project setup guide is available in the root [README.md](../README.md).

## Commands

```bash
npm install
npm start
npm run build
npm test
```

## Local Development

```bash
cd frontend
npm install
npm start
```

After the development server starts, open:

```text
http://localhost:4200/
```

API requests are proxied to the backend through `proxy.conf.json`.
